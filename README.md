# FinMind (Beta)

Mobile-first personal finance copilot with a 60-second snapshot and AI-driven insights.

## Structure
- client/  Vite + React + Tailwind PWA
- server/  Node.js + Express + SQLite
- shared/  (reserved for shared types)

## Quick start (after installing deps)
- Client: `cd client` then `npm install` and `npm run dev`
- Server: `cd server` then `npm install` and `npm run dev`
