# FinMind — TWA (Trusted Web Activity) Play Store Guide

## Prerequisites

1. **Deploy PWA** to a public HTTPS domain (e.g., `https://finmind.app`)
2. **Node.js 18+** installed
3. **Java JDK 11+** installed (for signing)
4. **Android SDK** (or use Bubblewrap which handles it)

---

## Step 1: Install Bubblewrap CLI

```bash
npm install -g @nicolo-ribaudo/bubblewrap
```

---

## Step 2: Generate Android Project

From the project root (where `twa-manifest.json` is):

```bash
bubblewrap init --manifest="https://finmind.app/manifest.webmanifest"
```

Or use the local config:

```bash
bubblewrap init --manifest="twa-manifest.json"
```

Bubblewrap will:
- Download Android SDK components (if needed)
- Generate the Android project in `./android/`
- Create a signing keystore (`android.keystore`)

---

## Step 3: Create Signing Keystore

If Bubblewrap doesn't prompt you, create one manually:

```bash
keytool -genkeypair -v \
  -keystore android.keystore \
  -alias finmind \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10000 \
  -storepass YOUR_STORE_PASSWORD \
  -keypass YOUR_KEY_PASSWORD \
  -dname "CN=FinMind, O=FinMind, L=Bangkok, C=TH"
```

---

## Step 4: Get SHA-256 Fingerprint

```bash
keytool -list -v -keystore android.keystore -alias finmind
```

Copy the **SHA-256** fingerprint (looks like `AB:CD:EF:...`).

---

## Step 5: Update Digital Asset Links

Edit `client/public/.well-known/assetlinks.json`:

```json
[
  {
    "relation": ["delegate_permission/common.handle_all_urls"],
    "target": {
      "namespace": "android_app",
      "package_name": "com.finmind.twa",
      "sha256_cert_fingerprints": [
        "AB:CD:EF:12:34:56:..."
      ]
    }
  }
]
```

**Deploy this file** to your web server. It MUST be accessible at:
```
https://finmind.app/.well-known/assetlinks.json
```

---

## Step 6: Build APK / AAB

```bash
bubblewrap build
```

This generates:
- `app-release-signed.apk` — for testing
- `app-release-bundle.aab` — for Play Store upload

---

## Step 7: Test APK

```bash
# Install on connected device
adb install app-release-signed.apk
```

Or use Android Studio emulator.

---

## Step 8: Upload to Play Store

1. Go to [Google Play Console](https://play.google.com/console)
2. Create a new app → **FinMind — AI Finance Copilot**
3. Upload the `.aab` file to **Production** or **Internal Testing**
4. Fill in:
   - **App name:** FinMind — AI Finance Copilot
   - **Short description:** AI-Powered Personal Finance Copilot
   - **Full description:** Track your wealth, get expert-level AI advice. Mobile-first financial dashboard with real-time metrics and actionable insights.
   - **Category:** Finance
   - **Screenshots:** Use the app on mobile, take screenshots
   - **Feature graphic:** 1024x500 banner
   - **Privacy policy URL:** (required)

## Play Store Checklist

| Requirement | Status |
|-------------|--------|
| HTTPS domain | ⬜ Deploy to `finmind.app` |
| `manifest.webmanifest` accessible | ⬜ After deploy |
| `assetlinks.json` with SHA-256 | ⬜ After keystore |
| Icons: 512x512 (any + maskable) | ✅ Generated |
| Splash screens | ✅ Generated |
| Offline support (service worker) | ✅ Workbox configured |
| `display: standalone` | ✅ In manifest |
| `start_url: /` | ✅ In manifest |
| `scope: /` | ✅ In manifest |
| Signing keystore | ⬜ Create with keytool |
| Privacy policy | ⬜ Required for Play Store |
| Screenshots (phone + tablet) | ⬜ Take from app |

## File Structure

```
FinMind/
├── twa-manifest.json              # Bubblewrap config
├── android.keystore               # Signing key (DO NOT COMMIT)
├── client/
│   └── public/
│       ├── .well-known/
│       │   └── assetlinks.json    # Digital Asset Links
│       ├── icon-512x512.png       # Play Store icon
│       ├── icon-maskable-512x512.png
│       ├── splash-portrait.png    # 1080x1920
│       └── splash-landscape.png   # 1920x1080
└── android/                       # Generated by Bubblewrap (gitignored)
```
